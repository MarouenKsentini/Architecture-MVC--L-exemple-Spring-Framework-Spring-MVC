# Architecture MVVM — L'exemple Angular

Atelier illustrant l'**architecture MVVM** (_Model – View – ViewModel_) avec **Angular**.

> 🚧 Branche de démarrage (vide). Le projet Angular sera ajouté ici.

## À venir

- **Model** : les données et services (`ProductService` → API REST).
- **View** : les templates/composants Angular (`.html`).
- **ViewModel** : les composants Angular (`.ts`) qui exposent un état observable (`RxJS`/signals) consommé par la vue.

## Création du projet Angular (prévu)

```bash
# Prérequis : Node.js + Angular CLI (ng)
ng new angular-mvvm
cd angular-mvvm
ng serve
# -> http://localhost:4200
```
